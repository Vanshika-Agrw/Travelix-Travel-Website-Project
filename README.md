🌍 Travelix – Travel Website Project

Travelix is a static travel website designed using HTML, CSS, and JavaScript.
It provides users with information about travel destinations, tour packages, itineraries, blogs, and contact details through a clean and user-friendly interface.

📌 Project Overview

Travelix is a front-end web project created to demonstrate:

-Website structure using HTML
-Styling and responsive design using CSS
-Basic interactivity using JavaScript

 Technologies Used
-HTML5 – Page structure
-CSS3 – Styling and layout
-JavaScript – Search functionality and interaction



Project Structure
Travelix/
travelk.html          # Home page
destinations.html    # Destinations page
iteneraries.html     # Travel itineraries

blogs.html           # Travel blogs
contact1.html        # Contact page

README.md            # Project documentation

Website Pages Description
-Home Page (travelk.html)
 -Hero section with background image
 -Search bar for travel services
 -Services like flights, hotels, packages, and cabs

-Destinations (destinations.html)
 -Popular travel destinations

-Itineraries (iteneraries.html)
 -Recommended itenaries

-Packages (packages.html)
 -Solo packages
 -Couple packages
 -Family packages

-Blogs (blogs.html)
 -Travel blogs for major cities

-Contact (contact1.html)
 -Contact information
 -User contact form

How to Run the Project
-Download or clone the project folder
-Open travelk.html in any web browser
-Navigate through the website using the menu

No server or database required

Features
-Responsive layout
